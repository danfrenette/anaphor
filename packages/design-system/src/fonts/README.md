# Inter

Inter 4.1 by Rasmus Andersson, distributed under the SIL Open Font License 1.1
in `Inter-LICENSE.txt`.

Original, unmodified WOFF2 files:
- https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
- https://rsms.me/inter/font-files/InterVariable-Italic.woff2?v=4.1

Both faces provide variable weight (100–900) and optical size (14–32) axes.
The shared stylesheet serves these files locally; no font CDN is used at runtime.

# Magda Clean Mono

Regular WOFF2 supplied by the user as `MagdaCleanMonoWeb W03 Regular.woff2`,
copied without modification to `MagdaCleanMono-Regular.woff2`.
The download's accompanying notice is retained as
`MagdaCleanMono-download-notice.txt`; it is a generic distributor notice,
not a verified font-specific license. Source: https://www.onlinewebfonts.com.

Only the regular (400) face is supplied. All bundled web font assets use WOFF2.
